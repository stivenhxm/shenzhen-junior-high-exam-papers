# 深圳初中试卷 · Shenzhen Junior High Exam Papers

收集和整理深圳初中各学科试卷，便于按学科、年级、学期和考试类型查找资料。

目前收录数学试卷，后续将陆续补充语文、英语、物理、化学等其他学科。

Exam papers for junior high schools in Shenzhen, China. Currently includes mathematics; more subjects will be added over time.

## 按题目和考点浏览

七年级和八年级上下学期题库收录了深圳学校、区级及联考试卷，也包括资料目录中的模拟卷与复习卷。下载仓库后，用浏览器打开 [题库首页](题库/index.html)，可以按卷阅读，也可以跨卷检索到具体小问。覆盖的卷子与来源见[已解析试卷登记表](题库/generated/已解析试卷.json)，后续批次的查重和入库步骤见[入库指南](题库/README.md)。

八上 288 个文件对应 125 份试卷，八下 411 个文件对应 189 份。原卷、评分标准、答题卡和不同编排版本均有逐文件登记。[八上来源清单](题库/batches/八年级上学期来源清单.json) · [八下来源清单](题库/batches/八年级下学期来源清单.json)

七下目录的 380 个源文件已对应到 90 份试卷，共 1,988 道大题。不同选项、题序或题目条件的版本可分卷查看。[七下逐文件来源清单](题库/batches/七年级下学期来源清单.json)

七上目录的 260 个源文件已对应到 117 份试卷，共 2,503 道大题、1,918 个显式小问。原卷、配套解析、答题卡和同卷异本均可按路径查询。[七上逐文件来源清单](题库/batches/七年级上学期来源清单.json)

## 查找与下载

- 从上方目录进入对应年级、学期，再按考试类型、学年或学校查找。
- 下载单个文件：打开文件页面，点击下载按钮或 **Download raw file**。
- 下载全部资料：点击仓库页面的 **Code → Download ZIP**，也可使用 Git 克隆。

## 后续更新

新增学科将放在仓库根目录的对应学科文件夹中，例如 `初中语文试卷/`、`初中英语试卷/`，并在本页补充索引。
